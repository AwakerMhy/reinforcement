# 条件效应和总体效应必须区分

令 C 表示准备态特征（如两组预训练A样本数差或动量方向），G=T_S−T_W，弱者平均更快当 G>0。总体平均差满足 E[G]=Σ_c P(C=c)E[G|C=c]；配对弱者先到率满足 P(T_W<T_S)=Σ_c P(C=c)P(T_W<T_S|C=c)。因此某个条件层的正效应不能外推到总群体，必须同时报告其准备概率和其他层结果。

自然风险分组主动学习中，之前均值反转的极端方向条件成对出现比例约.399%；总体熵查询平均差为−28.54±1.05（强者更快）。探索性较宽层 d=nA强−nA弱≥7 占约2.23%，弱者先到约68%，但独立4456对的均值差−.696±.882，不支持平均反转。配对胜率、均值与总体加权必须分别陈述。

自然位置分组动量实验中，之前筛选的有利方向条件约占10.9%；总体保留动量平均差−1.5736±.1213。故机制存在、条件效应与自然发生率是三种不同命题。详见 https://chatgpt.com/space/page_a416d51de74c81919729b0de9c753d73 。
