# 初态分布相图与真实数据的事前边界检验

理论背景：相同续训核下的Mpemba机制依赖初态在慢衰减方向上的投影，参见Lu与Raz 2017 https://pmc.ncbi.nlm.nih.gov/articles/PMC5441807/ 。本页分析二维GD的群体首达而非只比较两条曲线：L_i(t)=E_i[(1−F_i)a^t+F_i b^t]，a=.49，b=(1−.3/R)²，T_i(q)=min{t:L_i(t)≤q}。首达目标与起点总误差分布必须同时指定。所有正负配置完整报告，参数在运行前写入执行路线：https://chatgpt.com/space/page_c832da90f9588191a797822926070893 。

椭圆高斯分布反例：初态快慢风险能量E_i(1−μ_i)Z_f²、E_iμ_iZ_s²，E强=.04/E弱=.08；群体初始均值强<弱，但支持集重叠。μ各五格、每格100000对，筛选起点确实强<弱及双方未达q=.001后，25格的平均首达差全部为负，说明只看群体慢模态均值不足以确定条件配对首达。最有利配置(.9,.1)的筛选率约59.6%、差约−.98步；筛选后强/弱平均初始误差约.023/.112，起点差距显著大于Beta族。
