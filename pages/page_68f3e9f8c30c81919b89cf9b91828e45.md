# 非线性 Q 网络：同环境弱者较慢的独立结果

依[预先冻结协议](https://chatgpt.com/space/page_b2428790b6b08191bd87d8e997e18214)：三步 A/B MDP，8维状态特征，H=6 tanh 共享隐层，两个动作输出，全部参数可训练；输入权重 Gaussian sd .3，输出权重 sd .2，偏置零。半梯度 Q-learning α=.1、softmax 温度 .15、各预训练6回合，目标精确策略成功率 J≥.85。S 无 B 且 J∈[.55,.70)，W 有2/3次 B、至少一次 B 正奖励且 J∈[.40,.50)。所有 W 初始表现严格差于所有 S；两个组的训练环境、网络结构和更新规则完全相同。

独立150,000种子82,000,000+i：S n1810，初始 J .62432±.00102 SE，500回合限制的平均额外交互步64.851±2.741，中位21，10–90分位9–180；W n1933，J .45122±.00063，平均101.339±2.784，中位57，10–90分位18–243。S 1个500回合截尾，W无；S 的真实均值只会略高于所报限制均值。与探索阶段同方向，弱组在该非线性网络中明显更慢。

另用150,000独立准备种子83,000,000+i建池：S n1807、W n2055；配对种子84,000,000，3000对共享每回合情境与动作随机数（85,000,000+pair），最长1000回合且无截尾。3000/3000对 W 初始 J 更低。平均额外交互步 S60.195±1.923、W105.532±2.391；配对差 S−W=−45.337±2.751。W先到20.87%，S先到71.60%，平局7.53%。

反向传播 QA：对一个随机状态和网络，逐项中心有限差分检查61个相关参数的 Q 输出梯度，最大绝对误差4.45×10^-11。此负例与[部分共享线性正例、可实现压缩线性负例及表示交叉](https://chatgpt.com/space/page_4f5e7277c7b481918501933cc13b57b0)相互约束：现象不是任何共享网络的自动性质。仍需更广任务、不同网络与稳定性超参数；不能从单一非线性网络配置推断所有神经 Q 网络无效应。
