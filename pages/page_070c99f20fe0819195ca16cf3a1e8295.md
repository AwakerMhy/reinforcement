# Q 表示交叉：探索后冻结独立复核

固定三步 MDP、预训练6回合、同一结构性分组 S无B且J∈[.55,.70)，W有2/3次B、至少一次B正奖励且J∈[.40,.50)，共同目标J≥.85。首先在20参数可实现压缩线性 Q 表示中制备初态；随后将每个状态动作的 Q 值**精确映射**为表格模型 T_{s,a}=Q(s,a),U=0，分别由压缩、表格、部分共享 β=.5 的更新规则继续学习。投影前后所有初始 Q 与 J 逐点相同，三种续训条件共用每对未来情境/动作随机流；每一条件内 S/W 环境相同。探索150,000准备种子70,000,000+i、2000对、流72,000,000+pair：压缩 S/W 15.71/17.73步，表格40.78/45.47，部分共享42.45/40.28；全部无500回合截尾。先前交错实现曾异常显示全截尾，经逐模型独立续训实现复算并以单轨迹核对后弃用。现冻结三种更新规则、500回合上限，计划用新的准备种子73,000,000+i及配对/未来流74,000,000/75,000,000+pair做至少5000对独立复核，不论结果如何完整报告。
