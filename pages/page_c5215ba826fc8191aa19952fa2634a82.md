# 学习姆潘巴效应：神经网络与主动学习项目计划

制定于 2026-11-18。研究目标：在同一学习环境中检验初始评价损失更高的学习器，是否能以更少后续训练步数或标签查询达到共同损失阈值。当前已有二次损失、同分布 SGD 及等预算两步 MDP 的正例；MDP 严格弱组初始成功率 0.495 对强组 0.771，达标额外交互步数 16.2 对 40.1。详细记录见[已有进展](https://chatgpt.com/space/page_88afc7c10ca48191a02424aaa411a8a5)。

## 文献与核心判断

物理机制见 [Lu 与 Raz 2017](https://arxiv.org/abs/1609.05271)；宽神经网络的梯度训练存在核谱快慢模态，见 [Jacot 等 2018](https://arxiv.org/abs/1806.07572)；[Liu 与 Hu 2025](https://arxiv.org/abs/2507.04206)讨论 LLM 学习率调度中的 Mpemba 类机制。这说明网络输出不改变数据环境，也不排除被动训练出现反转。[Mussmann 与 Liang 2018](https://proceedings.mlr.press/v80/mussmann18a.html)和[Raj 与 Bach 2022](https://proceedings.mlr.press/v162/raj22a.html)表明不确定性主动采样的效率与收敛有条件限制，因此主动选样是待检验的额外机制。

## 阶段 1：被动有限宽网络

构造固定各向异性输入的两层有限宽 MLP。使用相同网络、权重先验、数据分布、预训练样本预算和优化器，从随机轨迹产生初始强弱分布；初始强弱只按同一固定评价集的 loss 排序。继续训练时使用相同数据分布及配对样本流。发现集只用于设定目标阈值和群体分层；独立种子验证初始损失、首次达标步数、曲线交点和配对胜率。加入单时间尺度、线性/核近似对照，记录快慢模态误差投影。若仅选中少数子群，报告占比。

## 阶段 2：同池主动学习

保持同一候选池、标签 oracle、网络、初始化来源、预训练预算、评价分布和查询预算。继续阶段分别测试随机查询与相同规则的预测熵查询；若熵失准，再测试模型分歧度。比较强弱组固定评价 loss 首次达标所需标签数、查询类别和置信度。对同一初始状态加入随机查询对照，区分被动谱效应与模型驱动采样的新增效应。检验过度自信和噪声导致失败的情形。

## 阶段 3：机制、稳健性与完成标准

被动情形从核/Hessian 模态投影推导损失交叉与首次达标条件；主动情形分析“参数状态→选样分布→参数更新”的反馈。扫描阈值、时间尺度比、网络宽度、预算与随机种子，并明确反转失效区域。完成标准：提供可执行复算代码、至少一个被动网络实验和一个主动学习对照的独立验证（正例或明确负结果）、首次达标统计与子群占比、机制与局限，并持续更新进展记录。由于本地工作区写入接口报错，代码和结果先保存在 Pages 并读回复算。

## 执行完成记录（2026-11-18）

本计划的完成标准已逐项实现。[实验结果与局限](https://chatgpt.com/space/page_fbd9be441e0c81919a337aa22a72ed78)记录：普通有限宽网络被动训练的独立验证正例、流式主动学习与同池随机查询的独立对照、经验 NTK 模态机制、输入尺度与目标阈值失败区、10% 标签噪声、宽度探索、以及更深一层网络的独立验证。[三段可执行复算代码](https://chatgpt.com/space/page_023e2aab78c88191939a29fbac14f558)均已从页面读出现场运行，输出与结果页吻合。

最重要的结论：主动学习不是学习姆潘巴效应的必要条件；被动有限宽 MLP 已有严格起点分离且独立验证的反转。预测熵主动选样能在当前构造中放大组间平均达标时间差，却比随机查询更耗标签，不能把这一结果解释为主动学习的总体效率增益。时间尺度接近时反转消失。分组来自发现阶段的事后筛选，子群比例已记录；后续研究应预注册分组并使用公开数据或更复杂任务检验外推。
