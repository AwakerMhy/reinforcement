# 精确小模型与表示边界（2026-11-19）

同一训练环境及转移核：状态 H（强者初始 J=.70）、M（弱者初始 J=.50）、L（陷阱）、A（目标 J≥.85，吸收）。H 每一步以概率 p=.7 达标，否则进入 L；M 每步以概率 r=.2 达标，否则留在 M；L 每步以概率 q 达标，否则留在 L。两组唯一差别是初始状态 H 或 M；转移规则完全相同。这里的 J 是独立给定的当前性能标签，抽象模型不直接等价于具体神经网络/RL 更新。

令首次达标时间 T 从 1 起计。E[T|H]=1+(1-p)/q，E[T|M]=1/r。弱者平均更快当且仅当 q<(1-p)/(1/r-1)，本例临界 q=.075。q=.05 时强者 7 步、弱者 5 步；q=.1 时强者 4 步、弱者 5 步，方向反转。

生存函数：P(T_H>t)=(1-p)(1-q)^(t-1)（t≥1）；P(T_M>t)=(1-r)^t。q=.05 时首次实数交叉 t=ln((1-q)/(1-p))/ln((1-q)/(1-r))=6.707，整数 t≥7 时强者尾部较大。生存曲线交叉比均值反转弱：q=.1 时也有生存交叉，但均值是强者更快。

固定预算 H 的截断均值：E[min(T_H,H)]=1+(1-p)[1-(1-q)^(H-1)]/q；E[min(T_M,H)]=[1-(1-r)^H]/r。q=.05 时 H=20 为强者4.7359、弱者4.9424（截断指标显示强者更快），H=22 几乎相等，H=23 为强者5.0588、弱者4.9705（弱者更快）。因此必须预先固定预算并报告删失率/生存曲线。

瞬态矩阵按(H,M,L)排列：Q=[[0,0,1-p],[0,1-r,0],[0,0,1-q]]。EμT=μ(I-Q)^(-1)1；有限时域 Eμ min(T,H)=Σ_{t=0}^{H-1} μQ^t1。慢模 λ=1-q 在强者 H 的准备态中有非零振幅，弱者 M 的准备态中为零。与统计物理中的慢模投影解释对应，但这里是训练达标的吸收时间，不是热平衡距离。

表示实验衔接：三步 RL 的混合私有+共享线性 Q（β=.5）在独立 5000 配对中强者122.398、弱者52.064 交互步；纯 20 参数、可表示最优 Q 的压缩线性模型为强者15.488、弱者18.323；共享隐藏层 H6 tanh Q 网络为强者60.195、弱者105.532。组内环境与后续规则一致。表示映射改变准备分布与更新核，初始性能顺序本身不足以决定达标顺序。参见本项目对应的预注册及结果 Page。

理论待检验：对任意同一个吸收核 Q，符号由 (μ_S-μ_W)(I-Q)^(-1)1 决定。若 Q 改变，需要同时测量准备分布对慢模的投影与更新核的变化；仅看局部特征内积或起点 J 不足。此精确模型是机制示例，不是对 RL 实验的定量拟合，也不构成高水平期刊充分证据。

配对概率（两名学习器使用同分布但独立的更新噪声）：q=.05 时 P(弱者先达标)=.25，P(强者先达标)=.60，P(同时)=.15；尽管弱者平均 5<7。理由是强者以 p=.7 立即吸收，但少数落入慢陷阱 L 的长尾抬高均值。令 d=q+r-qr，则 P(W先)= (1-p)r+(1-p)(1-r)r(1-q)/d，P(S先)=p(1-r)+(1-p)(1-r)q(1-r)/d。与主动学习实测中均值反转但 W-first<50% 的现象一致，提示主结论必须明确使用均值、配对胜率还是分位数。

对比文献：Lu 与 Raz 的 Markovian Mpemba 理论把异常弛豫联系到慢模振幅，参见 https://pmc.ncbi.nlm.nih.gov/articles/PMC5441807/ 。本项目需要证明的新增部分是训练参数/数据获取过程的吸收时间机制以及可证伪的表示依赖；不能把已有慢模解释本身当作新定理。

下一步实证缺口：需要在可复现的本地代码与真实任务上，估计准备态分布、删失生存曲线、完整特征传递核和目标对慢模的投影；在固定训练算法、目标和相同后续数据/交互流下预注册正负表示对照。当前执行环境的本地 shell 因 namespace 权限错误不可用，因此本轮新实验代码仍只有工具调用与 Page 参数/结果，尚未形成可独立运行的本地归档。

一个排除条件：若两名学习器可以在同一未来随机流下耦合，且任意 t 都保持 J_S(t)≥J_W(t)，则对共同阈值必有 T_S≤T_W 几乎处处，故任何意义上的弱者先到都不可能。若只有初始 J_S>J_W 而没有路径保序，反转可以发生。对固定同一吸收核 Q，h=(I-Q)^(-1)1 是每个参数态的剩余平均时间；性能排序与 h 的排序相反时，纯态起点立即给出平均时间反转。对分布起点则比较 (μ_S-μ_W)h。这个条件本身是首次到达时间恒等式，贡献在于将可测的准备分布与表示更新核放进同一个可证伪框架。

## 可复算的精确脚本

```js
// Node.js; exact finite-state learning first-passage model
const p = 0.7, r = 0.2;
function calc(q, H) {
  const meanS = 1 + (1-p)/q, meanW = 1/r;
  const truncS = 1 + (1-p)*(1-(1-q)**(H-1))/q;
  const truncW = (1-(1-r)**H)/r;
  const tailS = (1-p)*(1-q)**(H-1), tailW = (1-r)**H;
  const d = q + r - q*r;
  const wFirst = (1-p)*r + (1-p)*(1-r)*r*(1-q)/d;
  const sFirst = p*(1-r) + (1-p)*(1-r)*q*(1-r)/d;
  return {q,H,meanS,meanW,truncS,truncW,tailS,tailW,wFirst,sFirst,tie:1-wFirst-sFirst};
}
for (const q of [0.025,0.05,0.075,0.1]) {
  for (const H of [20,23,50]) console.log(calc(q,H));
}
const x=calc(0.05,50);
if (Math.abs(x.meanS-7)>1e-12 || Math.abs(x.meanW-5)>1e-12 ||
    Math.abs(x.wFirst-0.25)>1e-12 || Math.abs(x.sFirst-0.6)>1e-12)
  throw Error("exact checks failed");
```

有限预算的稳健性界：令 Q 与 Q̃ 是同一有限状态空间的次随机瞬态核，δ=||Q-Q̃||∞（最大行绝对和），h_H(Q)=Σ_{t=0}^{H-1}Q^t 1。由幂差望远镜展开和 ||Q||∞,||Q̃||∞≤1，有 ||h_H(Q)-h_H(Q̃)||∞≤δ H(H-1)/2。若两组准备分布的估计总变差误差分别为 e_S,e_W，则两组截断均值差的估计误差≤H(e_S+e_W)+δ H(H-1)。只有观测差超过这个界时，才能仅凭估计核/分布保证符号。界通常保守，尤其 H 大时；实践应配合直接配对重采样和删失生存曲线。
