# CliffWalking 动作优势选择器的独立复核结果

日期：2026-11-25。完整 6000 cohort 批次按先前已提交的[固定协议](2026-11-25_cliffwalking_margin_protocol.md)运行，协议提交 `ccceaba` 早于结果生成。选择器的参考路径定义和动作优势阈值来自旧研究；本批采用新随机种子、Gymnasium 1.4.0 官方确定性转移表、严格等环境步准备和固定的 25 步首达检查。

## 入组与计算成本

每池 64 名候选，各准备 2500 环境步；6000 池的参考策略均存在，4011 池同时具有初始贪心回报 −15 的强类和 −17 的弱类，1074 池又同时满足正向动作优势差 >1 与反向对照差 <−1，最终入组率 **17.9%**。准备交互总量为 960,000,000 步；贪心筛选另模拟 145,195,946 步，平均每个入组池约 **1,029,047 个**准备加筛选步骤。四条续训轨迹的重复贪心评价另模拟 5,810,266 步，不计入训练更新。

## 预定主结果

| 指标 | 正向动作优势组 | 反向对照组 |
|---|---:|---:|
| 强组平均首达环境步 | 105.49 | 97.04 |
| 弱组平均首达环境步 | 97.42 | 101.37 |
| 强−弱配对均值差 | **+8.08** | −4.33 |
| 配对标准误 | 2.74 | 2.78 |
| 95% 配对重采样区间 | **[+2.79, +13.41]** | [−9.78, +1.00] |
| 弱先／强先／同时 | 501／429／144 | 417／498／159 |
| 双方右删失 | 0 | 0 |

同一 cohort 中正向差减反向差的平均交互为 **+12.41 环境步**，配对标准误 3.62，20,000 次 cohort 重采样的描述性 95% 百分位区间为 **[+5.26, +19.46]**。正向主量及交互均满足协议中预定的正向判据；反向组自身区间跨零，不能单独宣称强者加速。正向组配对差中位数为 0；按 25 步网格，弱者在 1074 对中的 501 对先达，少于半数。这里成立的是**条件性群体均值反转**，不是“多数弱者先到”。

与[同任务朴素初始质量选组基线](2026-11-25_cliffwalking_result.md)的近零差不同，此固定的准备期动作优势指标在新的模拟批次中对首达排序有预测信号；两批的候选配对规则不同，不能将它们的均值直接相减作因果效应。正反向对照在本批共用候选池和未来随机流，使指标方向的比较更有解释力，但筛选依赖事先知道目标 −13 和同池优秀候选的参考路径，且代价约为每入组池百万环境步，远超 8 步平均续训优势。指标与结果的关联也不证明动作优势本身是致因机制。

本结果复核旧研究中的**单一确定性 CliffWalking 任务**条件效应，不构成 FrozenLake 或其他环境的外部验证；旧等回合准备造成的预算混杂仍须与本等步结果分开。训练由 Gymnasium 官方转移表驱动，未逐次调用 Python `step`；旧实现与可达状态转移已另行[核对](../results/cliffwalking_transition_audit.json)。配对重采样区间只反映此任务和固定生成协议下的模拟误差，不能当成跨任务置信区间。
