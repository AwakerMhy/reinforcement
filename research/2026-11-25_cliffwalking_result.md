# CliffWalking 等步预算基线结果

日期：2026-11-25。完整批次按先前推送的[固定协议](2026-11-25_cliffwalking_protocol.md)运行，协议提交 `f6415f1`。使用 Gymnasium 1.4.0 官方 `CliffWalking-v1` 确定性转移表；每个候选准备严格 2500 环境步，从同池选贪心初始回报 −15 的强者和 −17 的弱者。双方续训共享逐步探索随机数，每 25 个环境步检查是否达到共同贪心回报 ≥−13，上限 3000 步。选组不使用解析最优 Q 值或未来首达结果。

## 样本与信息成本

1000 个候选池中 658 个同时有合格强弱候选，入组率 65.8%。64×2500×1000=160,000,000 个准备环境交互步；另有 24,265,656 个模拟贪心评价步用于筛选。按全部候选池成本平均，每个入组配对需要约 280,039 个准备加筛选步骤。续训期间的反复贪心评估又使用 1,787,219 个模拟评价步；它们没有更新 Q 表，不能与训练步混算。

## 首达结果

| 指标 | 强组 | 弱组 |
|---|---:|---:|
| 入组配对 | 658 | 658 |
| 平均续训首达环境步 | 100.23 | 99.92 |
| 3000 步右删失 | 0 | 0 |
| 50 步累计达标 | 35.0% | 37.1% |
| 100 步累计达标 | 63.1% | 60.9% |
| 200 步累计达标 | 92.2% | 93.2% |
| 500 步累计达标 | 100% | 100% |

预定主量“强−弱首达环境步”均值为 **+0.30 步**，配对标准误 3.52 步；固定种子 20,000 次配对重采样的描述性 95% 百分位区间为 [−6.65, +7.22] 步。弱者先达 278 对，强者先达 282 对，同时 98 对；配对差中位数为 0。经验累计达标比例在 50 与 100 步之间改变排序，没有单向随机优势。全部入组对在 500 步前达标，因此本批结果不受右删失影响。

此朴素选组基线没有显示可靠的弱者更快效应，也不能证明精确零效应。它与[上一轮 FrozenLake 回合选组负结果](2026-11-25_frozenlake_rollout_result.md)共同说明：仅凭初始质量更差，不能预期标准 RL 任务中普遍弱者先达。两任务的准备、选组和目标不同，不能直接合并效应大小。旧 CliffWalking 的较大正差来自等回合预算混杂；后来用特定动作优势条件选组得到的小正差属于另一条件性问题，不能从本基线推出或否定该条件机制。

实现直接读取[官方转移导出表](../experiments/cliffwalking_transitions.json)，未逐次调用 Python Gymnasium `step`；在此之前已用[转移核对](../results/cliffwalking_transition_audit.json)验证旧复现规则的全部可达状态动作。单地图 658 个 cohort 的重采样区间只度量该配置的模拟误差，不代表 658 个独立 RL 环境。
